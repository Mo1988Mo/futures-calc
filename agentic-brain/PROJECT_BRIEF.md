# PROJECT BRIEF

## What We Built
TradeSmart Co. Knowledge Bot — a CLI tool that answers company
questions based on documents in the docs/ folder using Claude API.

## MVP Scope
- 3 company knowledge documents (FAQ, Leave Policy, Support Guide)
- Python CLI bot using Anthropic API
- React futures trading calculator (futures-trading-tool.jsx)

## Stack
- Frontend: React/JSX
- Bot: Python 3 + Anthropic SDK
- Docs: Markdown
- Hosting: GitHub + Netlify (planned)
